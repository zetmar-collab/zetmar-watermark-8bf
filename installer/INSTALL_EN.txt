SIGNATURE (WATERMARK) - plug-in for Photoshop and Photoshop Elements
Zetmar - Cyfrowy Przyjaciel, zetmar.net.pl
=================================================================

REQUIREMENTS
- Windows 10/11 64-bit
- Adobe Photoshop (CC, current versions), Photoshop Elements 2020 or newer (64-bit) or Affinity
- RGB images, 8 or 16 bits per channel

INSTALLATION (option 1: installer)
1. Close Photoshop / Elements.
2. Run ZetmarWatermark_Setup.exe. It detects the installed Adobe programs and offers to
   install into each of them. Untick the ones you do not want.
3. Start the program again.

INSTALLATION (option 2: manual)
1. Close Photoshop / Elements.
2. Copy ZetmarWatermark_64.8bf into the plug-ins folder:
   Photoshop:           C:\Program Files\Adobe\Adobe Photoshop <version>\Plug-ins\
   Photoshop Elements:  C:\Program Files\Adobe\Photoshop Elements <version>\Plug-Ins\
   (preferably into a Zetmar subfolder; administrator rights required)
   Or run install.ps1 (PowerShell) to do it automatically.
3. Start the program again.

AFFINITY
Affinity uses a separate file: ZetmarWatermark_Affinity_64.8bf (the same plug-in with a different plug-in
descriptor, because Affinity does not read the format used by Photoshop and Elements).
1. The installer copies this file to C:\Program Files\Common Files\Zetmar\AffinityPlugins.
2. In Affinity: Settings > Photoshop plugins > add that folder > restart Affinity.
3. Filter: Filters > Plugins > Zetmar > Signature (Watermark)...
Note: Affinity support is new and less tested than Photoshop and Elements.
If something goes wrong, create an empty file %APPDATA%\ZetmarWatermark\debug.flag - the plug-in will write log.txt.

WHAT'S NEW IN 1.1
- Drop shadow, tiled pattern across the whole image, alignment of multi-line text
- Auto color (white/black by photo brightness), preset export and import
- Fixes: stability with large signatures, faster logo preview, emoji with letter spacing

USAGE
1. Create an empty transparent layer (Ctrl+Shift+N).
2. Menu: Filter > Zetmar > Signature (Watermark)...
3. Set text or image, position, effects (stroke, emboss) and visibility. Click OK.
4. Set the blend mode and opacity in the Layers panel.
5. Ctrl+F repeats the filter with the last settings.
On a background layer the plug-in asks whether to apply the signature directly to that layer.

SETTINGS AND PRESETS
%APPDATA%\ZetmarWatermark\  (settings.json, presets folder)
Language (PL/EN) and window theme can be changed in the Settings tab.

UNINSTALL
Windows Settings > Apps > "Signature (Watermark)" > Uninstall,
or delete the Zetmar folder from the plug-ins folder.
